# 3D Satranç — Sürüm 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tarayıcıda çalışan, bilgisayara karşı ve aynı cihazda iki kişi oynanabilen, 2D + 3D görünümlü, taşları bir elin oynattığı, temaları klasörle eklenebilen satranç oyununu GitHub Pages'te yayınlamak.

**Architecture:** Dört katman: satranç çekirdeği (chess.js sarmalayıcı, `MoveEvent` üretir) → oyun yöneticisi (sıra, rakip, kayıt) → sahne (2D ve 3D görünüm, hareket modu) → arayüz. Görünümler yalnızca `MoveEvent` görür; hamle çekirdekte anında işlenir, animasyon arkadan oynar. Tema sistemi dört yuvayı (`ortam`, `masa`, `taslar`, `eller`) `tema.json` dosyalarından yükler.

**Tech Stack:** TypeScript, Vite, Three.js, chess.js, Stockfish (tek iş parçacıklı WASM, Web Worker), Vitest, Playwright, GitHub Actions + GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-11-11-3d-satranc-tasarim.md`

**Kapsam:** Yalnızca spec'teki "Sürüm 1". Sürüm 2 (yürüyen taşlar, ses, saat, maç geçmişi) ve Sürüm 3 (bulmaca, eğitim, analiz, PWA) ayrı planlardır.

```ts
// src/core/types.ts
export type Color = 'w' | 'b';
export type PieceType = 'p' | 'n' | 'b' | 'r' | 'q' | 'k';
export type Square = string; // 'a1'..'h8'
export interface MoveRequest { from: Square; to: Square; promotion?: PieceType }
export type GameResult =
  | { kind: 'ongoing'; check: boolean }
  | { kind: 'checkmate'; winner: Color }
  | { kind: 'draw'; reason: 'stalemate' | 'threefold' | 'fiftyMove' | 'insufficient' }
  | { kind: 'resigned'; winner: Color };
export interface MoveEvent {
  piece: PieceType; color: Color; from: Square; to: Square;
  captured?: { piece: PieceType; square: Square };
  special: 'none' | 'castleK' | 'castleQ' | 'enPassant' | 'promotion';
  promotion?: PieceType;
  rookMove?: { from: Square; to: Square };
  san: string; fenAfter: string; result: GameResult;
}
export interface PieceOnBoard { square: Square; piece: PieceType; color: Color }

// src/core/chessCore.ts
export class ChessCore {
  constructor(fen?: string);
  legalTargets(from: Square): Square[];
  needsPromotion(from: Square, to: Square): boolean;
  move(req: MoveRequest): MoveEvent | null;   // geçersizse null, durum değişmez
  undo(): boolean;
  turn(): Color;
  result(): GameResult;
  pieces(): PieceOnBoard[];
  fen(): string;
  pgn(): string;
  loadPgn(pgn: string): boolean;              // bozuksa false, durum değişmez
  history(): string[];                        // SAN listesi
}
```
